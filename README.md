# 🏢 층간소음 포렌식 분석 시스템 (Floor Noise Forensic Monitoring)

ESP32 기반의 **층간소음 실시간 감지 · 무결성 검증 · 법적 리포트 생성** 시스템입니다.
피에조 진동 센서로 천장/실내 충격을 측정하고, 각 이벤트를 **SHA-256으로 봉인**하여 변조 여부를 검증할 수 있는 웹 대시보드를 제공합니다.

> 단순 소음 측정이 아니라, **"이 데이터가 조작되지 않았음"을 증명하는 것**에 초점을 둔 프로젝트입니다.
> 실제 층간소음 분쟁 시 증거 자료의 신뢰성(Chain of Custody)을 확보하는 것이 목표입니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🔨 실시간 충격 감지 | 32번/34번 핀의 피에조 센서로 천장(cVib)·실내(iVib) 진동을 측정 |
| 🧠 Peak 유지 로직 | 루프를 빠르게 돌며 5초 구간 내 **최대 충격값**을 놓치지 않고 포착 |
| 🔐 SHA-256 무결성 봉인 | 각 이벤트를 해시로 봉인, 브라우저에서 재검증하여 변조 탐지 |
| 📊 실시간 대시보드 | Chart.js 기반 시간대별 빈도 · 소음 분포 · 일자별 누적 추이 시각화 |
| 🌡 환경 데이터 연동 | DHT22 센서로 측정 시점의 온도·습도 함께 기록 |
| 📥 CSV 다운로드 | 전체 로그를 CSV로 내보내기 |
| 📄 법적 리포트(PDF) | 무결성 검증 통과 데이터 기준으로 인쇄용 리포트 생성 |
| ⚠ 변조 시뮬레이션 | 데이터가 조작되면 시스템이 어떻게 탐지하는지 시연 |

## 🛠 하드웨어 구성

| 부품 | 용도 | 연결 핀 |
|------|------|---------|
| ESP32 개발보드 | 메인 컨트롤러 (WiFi 웹서버) | — |
| 피에조 진동 센서 ×1 | 천장 충격 측정 (cVib) | **GPIO 32** (ADC) |
| 피에조 진동 센서 ×1 | 실내 충격 측정 (iVib) | **GPIO 34** (ADC) |
| DHT22 | 온도·습도 측정 | **GPIO 4** |

> 💡 천장 센서(cVib)가 실내 센서(iVib)보다 유의미하게 클 때만 "윗집 소음"으로 판단합니다.
> 이를 통해 우리 집 내부에서 발생한 진동(발소리, 문 닫힘 등)을 걸러냅니다.

## 📦 필요 라이브러리

Arduino IDE에서 아래 라이브러리를 설치하세요.

- `WiFi.h` / `WebServer.h` — ESP32 보드 패키지에 기본 포함
- `time.h` — 표준 라이브러리 (NTP 시간 동기화)
- `mbedtls/sha256.h` — ESP32 코어에 기본 포함 (SHA-256 해싱)
- **`DHT sensor library`** (Adafruit) — DHT22 센서용, 별도 설치 필요

> ESP32 보드 매니저 URL:
> `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`

## 🚀 시작하기

### 1. WiFi 설정

코드 상단의 WiFi 정보를 본인 환경에 맞게 수정하세요.

```cpp
const char* WIFI_SSID     = "YOUR_WIFI_SSID";
const char* WIFI_PASSWORD = "YOUR_WIFI_PASSWORD";
```

> ⚠️ **보안 주의:** 공개 저장소(GitHub 등)에 올릴 때는 실제 WiFi 비밀번호를 절대 커밋하지 마세요.
> 위처럼 플레이스홀더로 바꾸거나 별도 설정 파일로 분리하는 것을 권장합니다.

### 2. 업로드 & 접속

1. Arduino IDE에서 보드를 **ESP32 Dev Module**로 설정
2. `.ino` 파일 업로드
3. 시리얼 모니터(**115200 baud**)를 열어 부팅 로그와 할당된 IP 확인
4. 브라우저에서 해당 **IP 주소로 접속** → 대시보드 표시

### 3. 시리얼 모니터 출력 예시

```
--- ESP32 부팅 성공! 코드 실행 시작 ---
웹 서버 실행 완료. 센서 감지를 시작합니다.
[실시간 모니터] 천장 충격값:  120 | 실내 충격값:   45
🚨 [웹 저장 완료] 유의미한 진동 포착! (기록된 천장 충격값: 812, 소음: 47.9dB)
```

## ⚙ 동작 원리

### 감지 & 저장 흐름

```
loop() 고속 반복
  │
  ├─ 센서값 계속 읽기 → 구간 내 최대(Peak)값 기억
  │
  ├─ 0.5초마다: 시리얼 모니터에 현재 Peak 출력
  │
  └─ 5초마다: processForensicAlgorithm() 호출
         │
         ├─ cVib > 100  AND  cVib > iVib × 1.5  일 때만 기록
         │   (노이즈 제거 + 윗집 소음 판별)
         │
         ├─ 타임스탬프 + 측정값을 문자열로 조합
         ├─ SHA-256 해시 생성 → 이벤트 봉인
         └─ events[] 배열에 저장 (최대 100건, 순환 저장)
```

### 무결성 검증 흐름

```
브라우저 대시보드
  │
  ├─ /api/events 에서 JSON 수신
  │
  ├─ 각 행의 (ts, lowRatio, cVib, iVib, temp, humid)로 SHA-256 재계산
  │
  └─ 저장된 hash와 비교
         ├─ 일치 → ✓ 정상 (통계에 포함)
         └─ 불일치 → ✗ 변조 (통계에서 제외 + 경고 배너)
```

## 🌐 API 엔드포인트

| 경로 | 메서드 | 설명 |
|------|--------|------|
| `/` | GET | 대시보드 HTML 페이지 |
| `/api/events` | GET | 저장된 이벤트 전체를 JSON으로 반환 |
| `/trigger` | GET | 테스트용 층간소음 이벤트 강제 발생 |

## 📁 데이터 구조

각 이벤트(`Event`)에 저장되는 필드:

| 필드 | 타입 | 설명 |
|------|------|------|
| `ts` | string | 측정 시각 (NTP 동기화, `YYYY-MM-DD HH:MM:SS`) |
| `lowRatio` | float | 저주파 비중 (%) |
| `cVib` | int | 천장 충격값 (0~4095) |
| `iVib` | int | 실내 충격값 (0~4095) |
| `db` | float | 환산 소음도 (dB) |
| `temp` / `humid` | float | 온도(°C) / 습도(%) |
| `hash` | string | SHA-256 무결성 봉인값 (64자) |

---

## ⚠ 참고 및 한계

- 소음도(dB)와 저주파 비중(lowRatio)은 실제 음압 측정이 아니라 **진동 센서값 기반의 환산치**입니다. 법적 효력을 위한 공인 측정과는 다릅니다.
- 이벤트는 최대 **100건까지 순환 저장**되며, 그 이상은 오래된 데이터부터 덮어씁니다. 장기 보관이 필요하면 CSV로 주기적으로 내보내세요.
- 데이터는 ESP32 메모리에만 있으므로 **재부팅 시 초기화**됩니다.
- `/trigger` 엔드포인트는 데모/테스트용이며 실제 센서값이 아닌 랜덤값을 생성합니다.
